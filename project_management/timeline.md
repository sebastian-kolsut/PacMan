# Project Timeline

## Overview

This document tracks the planned and actual progress of the Pac-Man project.

## Planned Timeline

| Phase | Planned Work | Planned Status |
|---|---|---|
| Project setup | Repository setup, dependency setup, project structure | Done |
| Maze generation | Integrate A-Maze-ing generator and render generated maze | Done |
| Core gameplay | Pac-Man movement, pacgums, collision, score, lives | Done |
| Ghost behavior | Add four ghosts, movement, frightened mode, respawn | Done |
| User interface | Main menu, instructions, highscores, pause, win/lose screens | Done |
| Configuration | JSON config parsing, comments support, validation | In progress |
| Cheat mode | Add F1-F5 cheat controls | Done |
| Audio and settings | Background music, volume control, wall color settings | Done |
| Packaging | Prepare executable build and packaging files | In progress |
| Testing and polishing | Run tests, fix edge cases, improve documentation | In progress |

## Actual Progress

| Date / Period | Work Completed |
|---|---|
| Initial phase | Project structure, MLX window, maze rendering |
| Gameplay phase | Player movement, pacgum collection, lives, score |
| UI phase | Main menu, instructions, highscores, pause and win/lose screens |
| Polish phase | Cheat mode, improved HUD, music, settings, final UI assets |
| Final phase | README, project management docs, validation, packaging, tests |

## Notes

Some UI and gameplay features were adjusted during development based on manual testing.  
The main remaining work is documentation, config hardening, testing, and final packaging verification.
